# Image Tagger

## Описание

Image Tagger - нейронная сеть, способная преобразовывать изображения в набор тегов-ассоциаций.

## Характеристики

- Обучение происходит на картинках формата 512x512. 
- Обучающая выборка предполагает изображения разных тематик для определения максимально возможного количества предметов и явлений.
- Максимальное количество тегов на выходе: 32.
